## Welcome to spinnaker!  A CD Foundation project

The docs and more information are available on the [main website](https://spinnaker.io)

The primary repo for [code, issues, PRs and similar is spinnaker/spinnaker](https://github.com/spinnaker/spinnaker).  This is a monorepo composed of multiple services that provide various functionality for the spinnaker CD platform.
For questions, please join the [spinnaker slack](https://join.slack.com/t/spinnakerteam/shared_invite/zt-3f4dqg66a-hX~tWeWPL3Sfnj3F8Ie2xg) and for governance, policies, see the [governance repo](https://github.com/spinnaker/governance).
